Interactive 3D showcase application that presents buildings and facilities surrounding Palembang Port. VTCV

3D maritime traffic visualization platform designed to monitor and present cargo vessel movements across operational shipping routes. The application visualizes vessel navigation between Merak and Bakauheni as well as port activities in Palembang, including arrival, berthing, departure, and transit operations. Users can switch between multiple camera perspectives to observe vessel movements and port activities from different viewpoints.

Unity C# 3D Visualization Maritime Simulation Camera System Monitoring
Live
ODOL (Over Dimension Over Load)

Operational training simulator that places users in a first-person inspection environment to evaluate vehicle compliance with over-dimension and overloading regulations before entering Merak Port. The application combines realistic inspection workflows, regulatory validation processes, and seamless web API integration to support training, assessment, and operational decision-making.

Unity C# 3D Visualization First-Person Simulation Training System Inspection Workflow REST API
Live
Rekayasa Lalulintas

Operational traffic management simulator developed to support congestion mitigation and traffic flow optimization around Merak Port. Users monitor and control vehicle releases from multiple rest areas, balancing traffic demand and roadway capacity to ensure smooth port access. The application integrates with web-based APIs to synchronize operational data and enhance simulation accuracy.

Unity C# Traffic Simulation Operational Planning REST API Decision Making
Live
Ticket Passengers

Ferry boarding and ticket validation platform designed to streamline passenger and vehicle verification processes before embarkation. The system integrates with web-based APIs to retrieve operational data, validate ticket information, and support efficient boarding workflows while ensuring compliance with transportation procedures.
